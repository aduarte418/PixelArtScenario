# PixelArt Scenario 2D - Unity

Repositorio para la actividad de creación de un escenario **Pixel Art en 2D con Unity**.

El repositorio contiene el proyecto de Unity, que puede ejecutarse directamente desde el editor.

Para comenzar, clona el repositorio en la carpeta donde desees guardar el proyecto y ábrelo desde Unity Hub.

## Controles

- **Flecha derecha / D:** Moverse a la derecha.
- **Flecha izquierda / A:** Moverse a la izquierda.
- **Espacio (Space):** Saltar.

## Notas a tener en cuenta

- No es posible trepar ni agarrarse a cornisas.
- El recorrido del mapa comienza en la puerta situada en el extremo izquierdo y termina en la señal de parking (P), situada en el extremo derecho.
- No hay *Triggers* implementados.

## Notas de ejecución

Al pulsar **Play** y centrar el foco en la ventana **Game**, se recomienda ajustar el tamaño (*Scale*) a **2x o 2.5x**, aunque puede modificarse según las preferencias de visualización.

El aspecto (*Aspect*) viene configurado por defecto en **16:9**, pero puede modificarse según las necesidades.

Hay que tener en cuenta que la resolución por defecto de la pantalla de juego es de **640x360 píxeles**.

## Posibles problemas durante la ejecución

Si al probar el proyecto y mover al personaje se encuentran muros invisibles o zonas en las que el personaje parece quedarse atascado, se recomienda:

1. Intentar mover al personaje hacia la izquierda o hacia la derecha.
2. Probar a saltar para salir de la zona en la que se encuentra atascado.

El personaje debería poder continuar moviéndose con normalidad después de realizar estas acciones.

**Nota:** Repetir este procedimiento cada vez que se produzca este comportamiento.
